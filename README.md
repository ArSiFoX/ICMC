# Image Context Menu Converter (Конвертер изображений)

Легковесное Windows-приложение для быстрой конвертации, изменения размера и сжатия изображений прямо из проводника Windows.

## 🚀 Основные возможности

-   **Интеграция в контекстное меню (ПКМ)**: Запускайте конвертер кликом правой кнопкой мыши по любому изображению.
-   **Поддержка форматов**: JPEG, PNG, BMP, GIF, WebP.
-   **Изменение размера**: Указывайте ширину или высоту с автоматическим сохранением пропорций (или без них).
-   **Умное соотношение сторон**: Отображение текущего и нового соотношения сторон в привычном формате (16:9, 4:3 и т.д.).
-   **Сжатие**: Настройка качества для JPEG и WebP.
-   **Предварительный расчет размера**: Программа показывает примерный вес итогового файла еще до сохранения.
-   **Продвинутые настройки**: Возможность вручную изменить имя файла и выбрать папку для сохранения.
-   **Портативность**: Один `.exe` файл, не требующий установки дополнительных библиотек (.NET включен внутрь).

## 🛠 Установка интеграции

1.  Скачайте или соберите файл `ImageContextMenuConverter.exe`.
2.  Запустите его.
3.  Нажмите кнопку **"Добавить в контекстное меню"**.
4.  Готово! Теперь при клике ПКМ по изображениям будет доступен пункт **"Конвертировать изображение"**.

*Примечание: Если вы переместите файл в другую папку, нажмите кнопку интеграции повторно, чтобы обновить путь в реестре.*

## 📖 Как пользоваться

1.  Нажмите ПКМ по картинке -> **"Конвертировать изображение"**.
2.  Выберите нужный формат в выпадающем списке.
3.  Если нужно, измените размеры (ширину или высоту).
4.  Настройте качество ползунком или введите число вручную.
5.  Посмотрите на **"Ожидаемый размер"**, чтобы оценить степень сжатия.
6.  Нажмите **"КОНВЕРТИРОВАТЬ И СОХРАНИТЬ"**.

## 💻 Технические детали

-   **Платформа**: .NET 8 (Windows Forms).
-   **Библиотека обработки**: SixLabors.ImageSharp.
-   **Сборка**: Self-contained, Single-file с включенным сжатием.
-   **Реестр**: Интеграция записывается в `HKEY_CURRENT_USER\Software\Classes\SystemFileAssociations\image\shell`, что не требует прав администратора.
